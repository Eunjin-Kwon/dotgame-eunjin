## 1. RALPLAN-DR 요약

### Principles
1. 기획서가 유일한 기준이다. 숫자(60/50/45초, 8/10/12방울, 거미 1마리·300 ms, 점수식)는 기획서 v3에 먼저 쓰고 코드·테스트는 그 숫자를 복사한다.
2. `src/logic.js`는 순수 함수만 둔다. Web Audio와 `localStorage`처럼 환경을 만지는 코드는 로직 밖(별 모듈 + `main.js` 배선)에 둔다. 로직은 부수효과 대슴 사건 이벤트를 내보내기만 한다.
3. 맵은 5장 문자 블록을 `src/levels.js`에 그대로 복사한다. **이 "좌표를 손으로 쓰지 않는다" 원칙은 `src/levels.js`의 맵 데이터에만 적용된다(AGENTS.md "좌표를 따로 적지 않는다"의 문맥은 맵 복사 규칙이다). 테스트의 기대값 좌표는 맵 문자 블록을 읽어 검산한 값이고, 테스트는 파싱 결과가 기획서 맵과 일치하는지를 검증하는 용도로만 좌표를 사용한다(N7).**
4. 구조를 늘리지 않는다. 레벨 차이는 맵·시간·방울 수뿐이고 거미는 모든 레벨 1마리다.
5. 완료는 테스트 통과가 아니라 사람이 브라우저에서 본 수용 기준이다. fixture 스크린샷은 증거가 아니다.

### Decision Drivers (top 3)
1. **착수 게이트가 기획서 커밋이다.** goal-4 코드는 design-v3 커밋 전에 시작할 수 없다(AGENTS.md + 결정 L). 그리고 v3는 **자기모순이 없어야** 사람에게 올릴 수 있다(pass 1 차단 사유).
2. **goal당 1회 시도, 최대 40분(결정 K).** 기존 `createWorld`/`enter`/`advance` 모양을 유지하는 최소 변경을 고른다.
3. **goal-5는 버릴 수 있는 goal이다.** 의존 방향은 한쪽(goal-5 → goal-4)이고, 못 끝내면 버리고 REPORT에 사실대로 적는다.

### Viable Options

**O1. 레벨 진행 상태를 어디에 두는가**
- **O1-A (채택): `logic.js`의 world에 `levelIndex`, `totalScore`를 넣고 전환을 순수 함수(`enter`)가 처리한다.**
  - 장: 전환·점수 누적·실패 재시작이 전부 `node --test`로 검증 가능. `render.js`/`main.js`는 world만 읽는다. phase는 `final` 하나만 추가.
  - 단: world 모양이 커지고 `test/goal3.test.js`의 클리어→타이틀 기대값을 v3 흐름으로 고쳐야 한다.
- **O1-B: 세션 상태를 `main.js`가 들고 `logic.js`는 레벨 하나만 알고 있는다.**
  - 장: `logic.js` 변경 최소. 단: 수용 31·33·36 상태 전이가 DOM 쪽으로 새어 wiring 테스트로만 검증 가능. 40분 제한에서 디버깅 비용이 더 크다. Architect도 Reject.
- 판단: O1-A.

**O2. 효과음·최고 점수를 어디에 두는가**
- **O2-A (채택): `src/audio.js`, `src/storage.js` 두 모듈 + `main.js` 배선. 두 모듈은 try/catch로 환경 실패를 삼킨다(콘솔 에러 금지 — 수용 37).**
  - 장: Principle 2 유지, 수용 37을 주입된 가짜 객체로 테스트 가능. 단: 파일 2개 추가(8장 모듈 목록에 적는다).
- **O2-B: `render.js`/`main.js` 안에 인라인.** 장: 파일 추가 없음. 단: `render.js`가 사이드이펙트를 갖고 테스트 불가.
- 판단: O2-A. **트리거 방식은 Architect 제안을 채택해 "로직이 이벤트를 내보내고 main.js가 소모"로 바꾼다(단계 3 상세 설계).**

**O3. 레벨 시간(60/50/45)을 어떻게 싣는가**
- **O3-A (채택): `levels.js`의 `LEVELS` 항목이 시간을 들고, 파싱된 level 객체에 `timeLimitS`가 실려 `createWorld`가 `level.timeLimitS`를 읽는다. 상수 `TIME_LIMIT_S`는 제거한다(호환 별칭 금지).**
- O3-B: `createWorld(level, nowMs, timeLimitS)` 인자 추가 → 호출부마다 숫자가 다시 들어가 "숫자는 한 곳" 규칙과 어긋난다.
- 판단: O3-A.

### 대안 무효화 근거 (옵션 1개만 남은 항목)
- **거미 수·속도**: 결정 A절이 모든 레벨 1마리·300 ms로 확정. 대안은 확정값 변경이라 검토하지 않는다.
- **맵 데이터**: 결정 C·D절 문자 블록이 확정이고 도달 가능성·방울 수 검증이 끝났다(레벨 2·3 = 12행×16열, 방울 10·12개, 거미 S = (7,6)·(5,3), 왕복 구간 x=1~14, P = (4,10)·(2,10)). 재생산 대안 없음.
- **최고 점수 저장 매체**: 결정 F절이 `localStorage` 키 하나 `dotgame-eunjin-highscore`로 확정. 서버·DB 대안은 AGENTS.md 금지와 충돌해 무효.
- **소리 소스**: 결정 E절 + AGENTS.md가 오디오 파일 금지 → Web Audio 합성만 가능.
